BLADE

Project

The question

The archives of late twentieth-century writers increasingly contain digital media: floppy disks, hard drives, word-processing files, email. These materials cannot be read like a manuscript. Yet they keep traces no manuscript has: overwritten versions, deleted fragments, system dates, residues of the programs in which the text was composed. BLADE asks how these traces can become philological evidence, and with which precautions.

The method

The project adapts the procedures of digital forensics to philological inquiry and documents them in a reproducible workflow:

  • imaging of the medium, bit by bit, without altering it;
  • metadata extraction from files and file systems;
  • file carving and recovery of fragments no longer indexed;
  • hexadecimal analysis and sequence alignment, on the model of bioinformatics;
  • emulation of the original writing environments.

The guiding image is that of textual DNA: the file as an ordered sequence of bases, to be read, compared and reconstructed.
